# Security and privacy policy

This repository is public. Do not commit or publish API keys, passwords, tokens,
private keys, `.env` files, credential-bearing URLs, private network addresses,
user-specific filesystem paths, personal email addresses, phone numbers, SSNs,
or other non-public personal or operational data.

Use local environment variables and GitHub repository secrets for credentials.
Keep real private values outside the repository and outside built browser assets.
Examples must use reserved placeholder values such as `example.com`.

If sensitive data is exposed, revoke or rotate it immediately; deleting the file
from the latest commit is not enough because Git history and deployments persist.
Report suspected exposure privately through this repository's **Security** tab.
